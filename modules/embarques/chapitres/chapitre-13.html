Une analyse MATLAB

MATLAB Analysis : un état à partir d'une mesure

Exemple du cours, « react on Counter measurement » : un compteur envoie ses mesures dans un channel ; une analyse MATLAB lit la mesure EPF, en déduit un état (0, 1 ou 2) et l'écrit dans un deuxième channel.

Étape 1 : créer les deux channels

  1. Channel de lecture counterAcquisition : Field 1 UF, Field 2 IF, Field 3 COSOHIF, Field 4 TF, Field 5 EPF, Field 6 state.
  2. Channel d'écriture counterState : Field 1 state.

Note l'ID et les clés des deux : la Read API Key de counterAcquisition, la Write API Key de counterState.

Tu dois voir : deux channels dans My Channels.

Étape 2 : créer l'analyse

Apps, MATLAB Analysis, New. Choisis le modèle qui lit un channel et écrit dans un autre (ou Custom, sans code), puis Create. Nomme-la stateCounterMatlab, efface le code et colle :

% TODO - Replace the [] with channel ID to read data from:
readChannelID = 0000000;        % ID de counterAcquisition
% TODO - Enter the Read API Key between the '' below:
readAPIKey = 'TA_CLE_READ';     % Read API Key de counterAcquisition

% TODO - Replace the [] with channel ID to write data to:
writeChannelID = 0000000;       % ID de counterState
% TODO - Enter the Write API Key between the '' below:
writeAPIKey = 'TA_CLE_WRITE';   % Write API Key de counterState

%% Read Data %%
data = thingSpeakRead(readChannelID, 'ReadKey', readAPIKey);

%% Analyze Data %%
% Add code in this section to analyze data and store the result in the
% 'analyzedData' variable.
%analyzedData = data
EPF = data(5);
if EPF < 80
    state = 0;
elseif EPF < 100
    state = 1;
else
    state = 2;
end
[EPF state]

%% Write Data %%
thingSpeakWrite(writeChannelID, state, 'Field', 1, 'WriteKey', writeAPIKey);

Remplace les deux IDs et les deux clés. Save.

Seuils du schéma du cours : EPF < 80, état 0 ; 80 ≤ EPF ≤ 100, état 1 ; EPF > 100, état 2. Le code, lui, teste EPF < 100 : pour EPF = 100 exactement, il donne 2 et non 1. Si tu veux suivre le schéma, écris elseif EPF <= 100.

Étape 3 : essayer à la main

Écris une mesure EPF de 70 dans counterAcquisition depuis le navigateur (Write API Key de counterAcquisition) :

https://api.thingspeak.com/update?api_key=TA_CLE_WRITE&field5=70

Reviens dans l'analyse et clique sur Save and Run.

Tu dois voir : dans Output, 70 0 (la mesure et l'état), et un point à 0 dans le channel counterState.

Une réaction React

Lab 3 : React App

Lancer l'analyse à la main ne sert à rien en vrai : React la déclenche toute seule quand une donnée arrive. React marche avec ThingHTTP, ThingTweet et MATLAB Analysis, pour agir quand les données d'un channel remplissent une condition.

Étape 1 : créer la réaction

Apps, React, New React. Les réglages de la capture du cours :

  • React Name : ReactStateCounter ;
  • Condition Type : String ; Test Frequency : On Data Insertion ;
  • Condition : If channel counterAcquisition, field 5 (EPF), is not equal to 0 ;
  • Action : MATLAB Analysis ; Code to execute : stateCounterMatlab ;
  • Options : Run action each time condition is met.

Save React.

Tu dois voir : ReactStateCounter dans la liste, cochée.

Étape 2 : comprendre les réglages

  • Condition Type : String, Status, Numeric, Geo Location ou No Data Check (vérifie que le channel reçoit bien des données à l'intervalle prévu).
  • Test Frequency : On Data Insertion (à chaque nouvelle donnée), ou toutes les 10, 30 ou 60 minutes, à l'heure pile.
  • Options : « only the first time » agit seulement quand la condition passe de fausse à vraie ; « each time » agit à chaque fois qu'elle est vraie.
  • Si l'analyse MATLAB plante plusieurs fois de suite, React s'arrête : coche « Notify me via email » dans l'analyse pour être prévenue.

Étape 3 : tester les trois états

Écris trois mesures dans counterAcquisition, en attendant au moins 15 s entre deux :

https://api.thingspeak.com/update?api_key=TA_CLE_WRITE&field5=70
https://api.thingspeak.com/update?api_key=TA_CLE_WRITE&field5=90
https://api.thingspeak.com/update?api_key=TA_CLE_WRITE&field5=110

Tu dois voir : dans counterState, l'état passe à 0, puis 1, puis 2 (les voyants jaune, vert et rouge des résultats du cours), sans avoir lancé l'analyse à la main.

Étape 4 : régler l'affichage d'un graphique

Un graphique de channel s'ouvre aussi par une requête HTTP GET, avec ses réglages dans l'adresse : title (titre), color (couleur de la ligne), width (largeur en pixels), xaxis (nom de l'axe).

https://api.thingspeak.com/channels/0000000/charts/1?title=Voltage&color=FF69B4&width=850&xaxis=Time

Tu dois voir : le graphique du champ 1, titré Voltage, avec une ligne rose et l'axe horizontal nommé Time. Si le channel est privé, ajoute &api_key=TA_CLE_READ à la fin.
