Créer le channel

Créer un channel ThingSpeak

ThingSpeak stocke les mesures de tes objets dans des channels, jusqu'à 8 champs (fields) chacun, et les trace tout seul. Avant de programmer l'ESP32, on crée le channel et on l'essaie depuis le navigateur.

Étape 1 : créer un compte

Va sur thingspeak.mathworks.com et crée un compte MathWorks (gratuit), ou connecte-toi.

Étape 2 : créer le channel

Channels, My Channels, New Channel. Donne un nom (par exemple ESP32 Lab), coche Field 1 et Field 2 et nomme-les Val1 et Val2. Save Channel.

Tu dois voir : la page du channel, avec son Channel ID et deux graphiques vides, Field 1 Chart et Field 2 Chart.

Étape 3 : noter l'ID et les clés

Note le Channel ID (en haut de la page). Onglet API Keys : note la Write API Key (pour écrire) et une Read API Key (pour lire).

Ces clés sont comme des mots de passe : ne les publie pas. Dans les programmes de ce site, elles sont remplacées par TA_CLE_WRITE et TA_CLE_READ.

Étape 4 : écrire depuis le navigateur

Une écriture ThingSpeak est une simple requête HTTP GET. Colle cette adresse dans le navigateur, en mettant ta Write API Key :

https://api.thingspeak.com/update?api_key=TA_CLE_WRITE&field1=70

Tu dois voir : un nombre seul dans la page : le numéro de l'entrée (1 la première fois). Dans Private View, un point à 70 sur Field 1 Chart.

La page répond 0 si l'écriture est refusée : clé fausse, ou deux écritures trop rapprochées. Avec un compte gratuit, ThingSpeak accepte une écriture toutes les 15 secondes environ.

L'ESP32 écrit dans le channel

Lab 1 : l'ESP32 écrit dans le channel

L'ESP32 fabrique deux valeurs (Val1 de 10 en 10, Val2 de 20 en 20) et les envoie dans Field 1 et Field 2 du channel, toutes les 5 secondes (CLK_TRANSMIT : 5 s dans le cours).

Étape 1 : coller le programme

Le programme du cours, assemblé à partir de ses diapositives (déclarations, setup, connexion Wi-Fi, données, écriture). Seuls les identifiants sont remplacés.

#include <WiFi.h>
#include "ThingSpeak.h"

const char* ssid = "TON_WIFI";          // your network SSID (name)
const char* password = "TON_MOT_DE_PASSE"; // your network password
WiFiClient client;
unsigned long myChannelNumber = 0000000;    // remplace par le Channel ID
const char * myWriteAPIKey = "TA_CLE_WRITE"; // remplace par la Write API Key

// Timer variables
unsigned long lastTime = 0;
unsigned long timerDelay = 5000;
float val1 = 0, val2 = 0;

void setup() {
  Serial.begin(115200);       // Initialize serial
  WiFi.mode(WIFI_STA);
  ThingSpeak.begin(client);   // Initialize ThingSpeak
}

void loop() {
  if ((millis() - lastTime) > timerDelay) {
    // Connect or reconnect to WiFi
    if (WiFi.status() != WL_CONNECTED) {
      Serial.print("Attempting to connect");
      while (WiFi.status() != WL_CONNECTED) {
        WiFi.begin(ssid, password);
        delay(5000);
      }
      Serial.println("\nConnected.");
    }

    // Get a new sensor reading
    val1 = val1 + 10;
    if (val1 > 100) val1 = 0;
    val2 = val2 + 20;
    if (val2 > 100) val2 = 0;
    Serial.print("Val1 : ");
    Serial.println(val1);
    Serial.print("Val2 : ");
    Serial.println(val2);

    // Write to ThingSpeak. There are up to 8 fields in a channel, allowing you to store up to 8
    // different pieces of information in a channel. Here, we write to field 1 and field 2.
    // int x = ThingSpeak.writeField(myChannelNumber, 1, val1, myWriteAPIKey);
    ThingSpeak.setField(1, val1);
    ThingSpeak.setField(2, val2);
    int x = ThingSpeak.writeFields(myChannelNumber, myWriteAPIKey);
    if (x == 200) {
      Serial.println("Channel update successful.");
    } else {
      Serial.println("Problem updating channel. HTTP error code " + String(x));
    }
    lastTime = millis();
  }
}

Étape 2 : mettre tes identifiants

  • ssid et password : ton Wi-Fi. L'ESP32 ne se connecte qu'en 2,4 GHz : un partage de connexion du téléphone marche bien.
  • myChannelNumber : le Channel ID, sans guillemets.
  • myWriteAPIKey : la Write API Key, entre guillemets.

Étape 3 : téléverser et regarder

Upload, puis Serial Monitor à 115200 bauds.

Tu dois voir : Attempting to connect, Connected., puis toutes les 5 s Val1 : 10.00, Val2 : 20.00 et Channel update successful. Sur ThingSpeak, les deux courbes montent en dents de scie.

Si une écriture sur deux affiche Problem updating channel. HTTP error code -401, c'est la limite d'une écriture toutes les 15 s du compte gratuit : passe timerDelay à 20000. Le code -301 veut dire que la carte ne joint pas ThingSpeak (Wi-Fi).

Étape 4 : une seule valeur

La ligne en commentaire écrit un seul champ à la fois. Pour essayer, mets en commentaire les trois lignes setField, setField, writeFields, et active celle-ci :

int x = ThingSpeak.writeField(myChannelNumber, 1, val1, myWriteAPIKey);

Tu dois voir : seule la courbe de Field 1 avance.

L'ESP32 lit le channel

Lire un champ du channel

Dans l'autre sens, une carte peut relire un channel : par exemple un afficheur au chevet qui montre la dernière fréquence cardiaque envoyée par un capteur.

Étape 1 : coller le programme

Programme assemblé autour de la diapositive « Read Channel Field » : la lecture est celle du cours ; la connexion Wi-Fi reprend celle du lab 1, et la lecture se répète toutes les 20 s.

#include <WiFi.h>
#include "ThingSpeak.h"

const char* ssid = "TON_WIFI";
const char* password = "TON_MOT_DE_PASSE";
WiFiClient client;
unsigned long myChannelNumberRead = 0000000;  // le Channel ID à lire
const char * myReadAPIKey = "TA_CLE_READ";    // sa Read API Key
unsigned int FieldNumber = 1;

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  ThingSpeak.begin(client);
}

void loop() {
  if (WiFi.status() != WL_CONNECTED) {
    Serial.print("Attempting to connect");
    while (WiFi.status() != WL_CONNECTED) {
      WiFi.begin(ssid, password);
      delay(5000);
    }
    Serial.println("\nConnected.");
  }

  // Read in field 1 of the private channel
  FieldNumber = 1;
  long val1 = ThingSpeak.readLongField(myChannelNumberRead, FieldNumber, myReadAPIKey);
  // Check the status of the read operation to see if it was successful
  int statusCode = ThingSpeak.getLastReadStatus();
  if (statusCode == 200) {
    Serial.println("Field1: " + String(val1));
  } else {
    Serial.println("Problem reading channel. HTTP error code " + String(statusCode));
  }
  delay(20000);
}

Mets ton Wi-Fi, le Channel ID et la Read API Key du channel du lab 1.

Étape 2 : téléverser et comparer

Laisse une carte (ou le navigateur) écrire dans le channel pendant que celle-ci lit. Avec une seule carte, écris des valeurs depuis le navigateur (lab précédent, étape 4).

Tu dois voir : toutes les 20 s, Field1: 70 (ou la dernière valeur écrite). Le code 200 de getLastReadStatus() veut dire que la lecture a réussi.

Étape 3 : lire plusieurs champs d'un coup

La deuxième diapositive lit tous les champs en une requête : fréquence cardiaque (champ 1), SpO2 (champ 2) et un résultat en texte (champ 3). Remplace le bloc de lecture de loop() (de FieldNumber = 1; jusqu'à l'accolade du else) par :

  // Read and store all the latest field values, location coordinates, status message, and created-at timestamp
  // use ThingSpeak.readMultipleFields(channelNumber, readAPIKey) for private channels
  int field[8] = {1, 2, 3, 4, 5, 6, 7, 8};
  int statusCode = ThingSpeak.readMultipleFields(myChannelNumberRead, myReadAPIKey);
  if (statusCode == 200) {
    // Fetch the stored data
    int HR1 = ThingSpeak.getFieldAsInt(field[0]);           // Field 1
    int SPO21 = ThingSpeak.getFieldAsInt(field[1]);         // Field 2
    String result = ThingSpeak.getFieldAsString(field[2]);  // Field 3
    Serial.println("HR=" + String(HR1));
    Serial.println("RESULT =" + result);
  } else {
    Serial.println("Problem reading channel. HTTP error code " + String(statusCode));
  }

Tu dois voir : HR=… et RESULT =…. Avec le channel du lab 1, HR montre Val1, et RESULT reste vide car le champ 3 n'existe pas : crée un champ 3 et écris-y du texte pour le voir.
