Préparer l'Arduino IDE

Préparer l'Arduino IDE pour l'ESP32

Les labs suivants se programment dans l'Arduino IDE, sur la carte ESP32 DEV KIT V1. Cette partie installe la carte et les trois bibliothèques des labs, une fois pour toutes.

Étape 1 : installer l'Arduino IDE

Télécharge l'Arduino IDE (version 2) : arduino.cc/en/software, et installe-le.

Étape 2 : ajouter les cartes ESP32

File, Preferences. Dans « Additional boards manager URLs », colle l'adresse des cartes d'Espressif :

https://espressif.github.io/arduino-esp32/package_esp32_index.json

OK, puis Tools, Board, Boards Manager. Cherche esp32 et installe « esp32 by Espressif Systems ».

Tu dois voir : « INSTALLED » sous esp32 by Espressif Systems.

Étape 3 : choisir la carte et le port

Branche l'ESP32 en USB. Tools, Board, esp32, DOIT ESP32 DEVKIT V1. Puis Tools, Port : le port de la carte (COM3, COM4… sous Windows).

Si aucun port n'apparaît : essaie un autre câble (certains ne font que charger), puis installe le pilote USB de la puce de ta carte, en général CP210x (Silicon Labs) ou CH340.

Étape 4 : installer les bibliothèques des labs

Sketch, Include Library, Manage Libraries. Cherche et installe :

  • ArduinoJson de Benoit Blanchon (lab 2) ;
  • ThingSpeak de MathWorks (lab 3) ;
  • PubSubClient de Nick O'Leary (labs 4 et 6).

Les bibliothèques WiFi.h et BluetoothSerial.h viennent avec les cartes ESP32 : rien à installer.

Le code du cours est écrit pour ArduinoJson 6 (StaticJsonDocument, createNestedArray). Pour suivre sans surprise, choisis une version 6.x dans la liste des versions. La version 7 compile aussi, avec des avertissements « deprecated ».

Étape 5 : téléverser et ouvrir le moniteur série

Pour chaque programme : bouton Upload (flèche vers la droite), puis Tools, Serial Monitor, et règle la vitesse (en bas à droite) sur celle de Serial.begin : 9600 pour ce lab, 115200 pour les suivants.

Si le téléversement s'arrête sur Connecting.... puis Failed to connect, maintiens le bouton BOOT de la carte pendant que les points s'affichent, puis relâche.

Générer un document JSON

JSON generator example

L'ESP32 doit envoyer une mesure à un serveur : il faut l'emballer en JSON. La bibliothèque ArduinoJson construit le document clé par clé, puis l'écrit en texte (partie 4.1 du cours).

Étape 1 : coller le programme du cours

Crée un nouveau sketch (File, New Sketch), efface tout et colle :

// ArduinoJson - https://arduinojson.org
// Copyright Benoit Blanchon 2014-2021
// MIT License
//
// This example shows how to generate a JSON document with ArduinoJson.
//
// https://arduinojson.org/v6/example/generator/

#include <ArduinoJson.h>

void setup() {
  // Initialize Serial port
  Serial.begin(9600);
  while (!Serial) continue;
  StaticJsonDocument<200> doc;
  doc["sensor"] = "gps";
  doc["time"] = 1351824120;

  // Add an array.
  JsonArray data = doc.createNestedArray("data");
  data.add(48.756080);
  data.add(2.302038);

  // Generate the minified JSON and send it to the Serial port.
  serializeJson(doc, Serial);
  // The above line prints:
  // {"sensor":"gps","time":1351824120,"data":[48.756080,2.302038]}

  // Start a new line
  Serial.println();

  // Generate the prettified JSON and send it to the Serial port.
  //
  serializeJsonPretty(doc, Serial);
  // The above line prints:
  // {
  //   "sensor": "gps",
  //   "time": 1351824120,
  //   "data": [
  //     48.756080,
  //     2.302038
  //   ]
  // }
}

void loop() {
  // not used in this example
}

Étape 2 : téléverser et lire le résultat

Upload, puis Serial Monitor à 9600 bauds. Appuie sur le bouton EN (reset) de la carte si rien ne s'affiche : setup() ne tourne qu'une fois.

Tu dois voir : la version compacte {"sensor":"gps","time":1351824120,"data":[48.75608,2.302038]}, puis la même en version lisible, une clé par ligne. Le nombre de décimales affichées peut différer un peu de celui des commentaires du cours.

Étape 3 : comprendre ce que fait chaque ligne

  • StaticJsonDocument<200> doc; réserve 200 octets pour le document.
  • doc["sensor"] = "gps"; ajoute une paire clé-valeur.
  • createNestedArray("data") ajoute un tableau, rempli avec add.
  • serializeJson écrit le texte compact (celui qu'on envoie sur le réseau) ; serializeJsonPretty l'écrit avec retours à la ligne, pour le lire.

Étape 4 : à toi (exercice ajouté)

Fais produire à l'ESP32 le message du power meter du lab 1, {"V":220,"I":20}. Essaie seul, puis compare :

// Exercice ajouté : le message du power meter (lab 1), produit par l'ESP32
#include <ArduinoJson.h>

void setup() {
  Serial.begin(9600);
  while (!Serial) continue;
  StaticJsonDocument<200> doc;
  doc["V"] = 220;
  doc["I"] = 20;
  serializeJson(doc, Serial);   // {"V":220,"I":20}
  Serial.println();
}

void loop() {
}

Tu dois voir : {"V":220,"I":20} dans le moniteur série. C'est le message que Node-RED savait déjà découper.

Lire un document JSON

JSON parser example

Dans l'autre sens, l'ESP32 reçoit un texte JSON (par exemple d'un serveur) et doit en tirer chaque valeur. ArduinoJson le lit, le vérifie, puis donne accès aux champs (partie 4.2 du cours).

Étape 1 : coller le programme du cours

// This example shows how to deserialize a JSON document with ArduinoJson.
#include <ArduinoJson.h>

void setup() {
  // Initialize serial port
  Serial.begin(9600);
  while (!Serial) continue;
  StaticJsonDocument<200> doc;
  char json[] =
      "{\"sensor\":\"gps\",\"time\":1351824120,\"data\":[48.756080,2.302038]}";

  // Deserialize the JSON document
  DeserializationError error = deserializeJson(doc, json);

  // Test if parsing succeeds.
  if (error) {
    Serial.print(F("deserializeJson() failed: "));
    Serial.println(error.f_str());
    return;
  }

  // Fetch values.
  //
  // Most of the time, you can rely on the implicit casts.
  // In other case, you can do doc["time"].as<long>();
  const char* sensor = doc["sensor"];
  long time = doc["time"];
  double latitude = doc["data"][0];
  double longitude = doc["data"][1];

  // Print values.
  Serial.println(sensor);
  Serial.println(time);
  Serial.println(latitude, 6);
  Serial.println(longitude, 6);
}

void loop() {
  // not used in this example
}

Étape 2 : téléverser et lire le résultat

Upload, Serial Monitor à 9600 bauds, puis bouton EN si besoin.

Tu dois voir : quatre lignes : gps, 1351824120, 48.756080 et 2.302038 (6 décimales, demandées par println(latitude, 6)).

Étape 3 : provoquer une erreur

Retire l'accolade finale du texte JSON (la dernière } avant le guillemet fermant) et téléverse à nouveau.

Tu dois voir : deserializeJson() failed: IncompleteInput. Le programme teste error avant de lire les champs : un message abîmé ne donne pas de fausses valeurs. Remets l'accolade.
