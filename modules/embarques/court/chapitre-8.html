JSON et la plateforme ThingSpeak

Lire le cours complet

JSON

Format léger d'échange : des paires nom/valeur dans des accolades { } (objets) et des listes dans des crochets [ ] (tableaux). Noms et chaînes entre guillemets doubles. Types : nombre, chaîne, booléen (true, false), tableau, objet, null.

ThingSpeak

  • Un channel a un Channel ID et jusqu'à 8 fields.
  • Deux clés : Write API Key (écrire) et Read API Key (lire un channel privé).
  • Écrire en HTTP : GET https://api.thingspeak.com/update?api_key=CLE&field1=valeur.
  • Sur l'ESP32 : setField(1, v), puis writeFields(...) ; 200 veut dire réussi.
  • Apps : MATLAB Analysis (calculer sur les données), React (agir quand une condition est remplie).

ThingSpeak en MQTT

Broker mqtt3.thingspeak.com, port 1883 ; un device MQTT porte Client ID, Username, Password. Le broker répond CONNACK à la connexion, SUBACK à l'abonnement.

  • Publier tous les champs : channels/ID/publish, message field1=45&field2=60.
  • Publier un champ : channels/ID/publish/fields/field1.
  • S'abonner : channels/ID/subscribe : chaque entrée arrive en JSON.
  • ESP32 (PubSubClient) : setServer, connect, publish, subscribe, setCallback, loop().

Questions d'examen

Réponds dans ta tête, puis touche « Voir la réponse ».

1. Comment JSON écrit-il un objet ? Un tableau ?

Voir la réponse

Objet : paires nom/valeur entre accolades { }.

Tableau : valeurs séparées par des virgules entre crochets [ ].

2. Ce JSON est-il valide : {'hr': 72} ?

Voir la réponse

Non : les noms et les chaînes doivent être entre guillemets doubles, {"hr": 72}.

3. Combien de champs a un channel ThingSpeak ?

Voir la réponse

Jusqu'à 8.

4. Quelle clé pour écrire ? Pour lire un channel privé ?

Voir la réponse

Write API Key pour écrire.

Read API Key pour lire.

5. Écris l'URL qui met 37 dans le champ 2.

Voir la réponse

https://api.thingspeak.com/update?api_key=CLE&field2=37

6. Que veut dire writeFields(...) == 200 ?

Voir la réponse

L'écriture dans le channel a réussi.

7. Sur quel topic publier tous les champs en MQTT ?

Voir la réponse

channels/ID/publish, avec un message du type field1=45&field2=60.

8. Pourquoi appeler loop() dans le programme MQTT de l'ESP32 ?

Voir la réponse

Pour garder la connexion au broker et traiter les messages reçus (callback).
