Les broches

  • GPIO 34, 35, 36, 39 : entrées seulement, jamais une sortie.
  • ADC2 : inutilisable quand le Wi-Fi tourne.

Du code ADC à la force

  • \(V^+ = 3{,}3 \times 10 / 120 = 0{,}275\) V : sans appui, le code reste vers 341.
  • Code vers tension : \(V_A = \text{code} \times 3{,}3 / 4095\).
  • Tension vers résistance : \(R_{FSR} = R_G / (V_A / V^+ - 1)\), infinie si \(V_A \le V^+\).
  • Résistance vers force : \(F = \beta / (R_{FSR} - R_0)\).

Les quatre fonctions

  • configSensors() : S1 à S3 en OUTPUT, analogReadResolution(12).
  • selectSensor(num) : digitalWrite(S1, num & 1), (num >> 1) & 1 pour S2, (num >> 2) & 1 pour S3.
  • sensorAcquisition(num) : sélectionner, attendre 2 ms (stabilisation du filtre \(R_G C_F\)), analogRead(AIN1).
  • rsensor(val) : les deux conversions ci-dessus.

Version 1 : modes et bouton

  • float mesures[8]; : une case par voie.
  • Mode 0 : une mesure du capteur num. Mode 1 : moyenne de N mesures de num. Mode 2 : moyenne de N mesures pour chacun des 8.
  • On moyenne les codes, puis on convertit une seule fois en résistance.
  • Bouton : appuyé = LOW ; on réagit au passage de HIGH à LOW, puis on laisse passer les rebonds.

Version 2 : le timer

  • timerBegin(1000000) : un pas par µs (pré-diviseur 80 sur 80 MHz).
  • timerAlarm(timer, 1000000, true, 0) : 1 000 000 pas = 1 s, rechargement auto.
  • L'interruption ne fait que tick = true; (variable volatile) ; loop() baisse le drapeau et lance acquisition(2, 0, N).
  • Annexe à corriger : elle attache onTimer mais définit onTimer0, et ne déclare pas tick.

Questions d'examen

Réponds dans ta tête, puis touche « Voir la réponse ».

1. Peut-on commander S1 avec GPIO 35 ?

Voir la réponse

Non : GPIO 34 à 39 sont des entrées seulement.

2. Pourquoi lire AIN1 sur l'ADC1 ?

Voir la réponse

Les broches de l'ADC2 ne marchent plus quand le Wi-Fi est utilisé.

3. selectSensor(3) : que valent S3 S2 S1 ?

Voir la réponse

3 s'écrit 011 : S1 = 1, S2 = 1, S3 = 0.

4. Pourquoi attendre avant analogRead() après un changement de capteur ?

Voir la réponse

\(V_A\) doit se stabiliser : le filtre \(R_G C_F\) demande environ \(5 R_G C_F\), 1,8 ms avec 470 pF.

5. Le code lu vaut 1638. Quelle résistance ?

Voir la réponse\[V_A = \frac{1638 \times 3{,}3}{4095}\]\[V_A \approx 1{,}32\ \text{V}\]\[R_{FSR} = \frac{750}{1{,}32 / 0{,}275 - 1}\]\[R_{FSR} \approx 197\ \text{k}\Omega\]

6. Que renvoie rsensor() si \(V_A \le V^+\) ?

Voir la réponse

Une résistance infinie (INFINITY) : pas d'appui, et pas de division par zéro ni de résistance négative.

7. Pourquoi moyenner les codes plutôt que les résistances ?

Voir la réponse

Le bruit est sur la tension.

La relation tension-résistance n'est pas linéaire : la moyenne des résistances n'est pas la résistance de la tension moyenne.

8. timerBegin(1000000) : quelle alarme pour une période de 1 s ? De 25 ms ?

Voir la réponse\[\text{alarme} = \frac{T}{T_{tic}}\]

1 s / 1 µs = 1 000 000.

25 ms / 1 µs = 25 000.

9. Pourquoi l'acquisition n'est-elle pas faite dans l'interruption ?

Voir la réponse

Elle dure plusieurs millisecondes (attentes, 80 conversions) : trop long pour une interruption.

L'interruption lève un drapeau ; la boucle mesure.
