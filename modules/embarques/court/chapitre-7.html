Modèles et protocoles de communication

Version courte : l'essentiel, puis les questions. Lire le cours complet

Quatre modèles

  • Request-Response : le client demande, le serveur répond.
  • Publish-Subscribe : les publishers envoient sur des topics à un broker, qui distribue aux abonnés ; personne ne connaît personne.
  • Push-Pull : les producteurs poussent dans des files, les consommateurs tirent ; la file sert de tampon.
  • Exclusive Pair : connexion persistante, bidirectionnelle, full duplex.

HTTP

Ressource désignée par une URL. Méthodes : GET (lire), POST (envoyer), PUT (remplacer), DELETE (supprimer), HEAD, OPTIONS, PATCH, TRACE. Le client parle toujours le premier : un objet doit venir demander. Modèle OSI en 7 couches (application à physique).

MQTT

Publish/subscribe léger sur TCP/IP, pour les appareils limités. Topics en chemins : home/groundfloor/kitchen/temperature. Jokers : + (un niveau), # (tous les niveaux suivants).

QoSLivraison
0au plus une fois, sans confirmation (rapide)
1au moins une fois, doublons possibles
2exactement une fois, échange en 4 étapes (le plus fiable)

WebSockets et RPC

WebSocket : bidirectionnel, full duplex, une seule connexion TCP ; le serveur peut parler de lui-même (alarme sur un tableau de bord). RPC : appeler une procédure distante comme une procédure locale.

Questions d'examen

Réponds dans ta tête, puis touche « Voir la réponse ».

1. Dans le modèle publish-subscribe, quel est le rôle du broker ?

Voir la réponse

Il reçoit les messages publiés sur les topics et les distribue à tous les abonnés ; publishers et abonnés ne se connaissent pas.

2. Quelle méthode HTTP pour lire une ressource ? Pour la remplacer ?

Voir la réponse

GET pour lire.

PUT pour remplacer.

3. Pourquoi un interrupteur en HTTP doit-il interroger le serveur ?

Voir la réponse

En HTTP, le client parle toujours le premier : l'interrupteur doit venir demander s'il doit s'éteindre.

4. Quels messages reçoit un abonné à home/groundfloor/+/temperature ?

Voir la réponse

Les températures de toutes les pièces du rez-de-chaussée (un seul niveau remplacé par +).

5. Et un abonné à home/groundfloor/# ?

Voir la réponse

Toutes les mesures de toutes les pièces du rez-de-chaussée.

6. Quelle QoS si l'on ne veut aucun doublon ?

Voir la réponse

QoS 2 : exactement une fois.

7. Que règlent les WebSockets par rapport à HTTP ?

Voir la réponse

Elles sont bidirectionnelles, full duplex, et gardent une seule connexion TCP : le serveur peut envoyer de lui-même.

8. Qu'est-ce que le RPC ?

Voir la réponse

Une technique client-serveur qui permet d'appeler une procédure distante comme une procédure locale.
