JSON generator example

L'ESP32 doit envoyer une mesure à un serveur : il faut l'emballer en JSON. La bibliothèque ArduinoJson construit le document clé par clé, puis l'écrit en texte (partie 4.1 du cours).

Étape 1 : coller le programme du cours

Crée un nouveau sketch (File, New Sketch), efface tout et colle :

// ArduinoJson - https://arduinojson.org
// Copyright Benoit Blanchon 2014-2021
// MIT License
//
// This example shows how to generate a JSON document with ArduinoJson.
//
// https://arduinojson.org/v6/example/generator/

#include <ArduinoJson.h>

void setup() {
  // Initialize Serial port
  Serial.begin(9600);
  while (!Serial) continue;
  StaticJsonDocument<200> doc;
  doc["sensor"] = "gps";
  doc["time"] = 1351824120;

  // Add an array.
  JsonArray data = doc.createNestedArray("data");
  data.add(48.756080);
  data.add(2.302038);

  // Generate the minified JSON and send it to the Serial port.
  serializeJson(doc, Serial);
  // The above line prints:
  // {"sensor":"gps","time":1351824120,"data":[48.756080,2.302038]}

  // Start a new line
  Serial.println();

  // Generate the prettified JSON and send it to the Serial port.
  //
  serializeJsonPretty(doc, Serial);
  // The above line prints:
  // {
  //   "sensor": "gps",
  //   "time": 1351824120,
  //   "data": [
  //     48.756080,
  //     2.302038
  //   ]
  // }
}

void loop() {
  // not used in this example
}

Étape 2 : téléverser et lire le résultat

Upload, puis Serial Monitor à 9600 bauds. Appuie sur le bouton EN (reset) de la carte si rien ne s'affiche : setup() ne tourne qu'une fois.

Tu dois voir : la version compacte {"sensor":"gps","time":1351824120,"data":[48.75608,2.302038]}, puis la même en version lisible, une clé par ligne. Le nombre de décimales affichées peut différer un peu de celui des commentaires du cours.

Étape 3 : comprendre ce que fait chaque ligne

  • StaticJsonDocument<200> doc; réserve 200 octets pour le document.
  • doc["sensor"] = "gps"; ajoute une paire clé-valeur.
  • createNestedArray("data") ajoute un tableau, rempli avec add.
  • serializeJson écrit le texte compact (celui qu'on envoie sur le réseau) ; serializeJsonPretty l'écrit avec retours à la ligne, pour le lire.

Étape 4 : à toi (exercice ajouté)

Fais produire à l'ESP32 le message du power meter du lab 1, {"V":220,"I":20}. Essaie seul, puis compare :

// Exercice ajouté : le message du power meter (lab 1), produit par l'ESP32
#include <ArduinoJson.h>

void setup() {
  Serial.begin(9600);
  while (!Serial) continue;
  StaticJsonDocument<200> doc;
  doc["V"] = 220;
  doc["I"] = 20;
  serializeJson(doc, Serial);   // {"V":220,"I":20}
  Serial.println();
}

void loop() {
}

Tu dois voir : {"V":220,"I":20} dans le moniteur série. C'est le message que Node-RED savait déjà découper.
