Le dashboard Node-RED

Les valeurs défilent dans le panneau debug, mais un soignant veut des cadrans et des courbes. Le dashboard affiche le power meter dans une page web, sur le PC ou sur un téléphone du même réseau.

Étape 1 : ajouter les cadrans et les courbes

Dans la palette, catégorie dashboard :

  1. Glisse trois nœuds gauge : Current (A), Voltage (V), Power (W). Relie chaque fonction (current, voltage, power) à son cadran.
  2. Glisse trois nœuds chart et relie aussi chaque fonction à sa courbe.
  3. Dans chaque cadran, Group : crée un groupe Measurement dans un onglet (tab) IoT Lab. Mets les courbes dans un deuxième groupe, Group 2.
  4. Règle Range (min, max) : par exemple 0 à 30 A, 0 à 250 V, 0 à 6000 W. Le cours garde 0 à 10, l'aiguille resterait alors collée au bout.

Pour les courbes, mieux vaut des nombres : mets Number(msg.payload.I) et Number(msg.payload.V) dans current et voltage. Le flux à importer plus bas le fait déjà.

Étape 2 : afficher le dashboard

Deploy, puis ouvre http://127.0.0.1:1880/ui. Publie quelques mesures :

cd "C:\Program Files\mosquitto"
mosquitto_pub -h localhost -t sensors -m "{\"V\":\"220\",\"I\":\"20\"}"
mosquitto_pub -h localhost -t sensors -m "{\"V\":\"230\",\"I\":\"12\"}"
mosquitto_pub -h localhost -t sensors -m "{\"V\":\"215\",\"I\":\"25\"}"

Tu dois voir : la page IoT Lab : le groupe Measurement avec les cadrans (Power 4400 W, puis 2760, puis 5375) et le groupe 2 avec les courbes qui suivent chaque message.

Étape 3 : voir le dashboard sur un autre appareil

Le dashboard est une page web servie par ton PC. Sur un téléphone ou une tablette connecté au même Wi-Fi, ouvre Ton_adresse_IP:1880/ui. Pour trouver l'adresse IP du PC :

ipconfig

Tu dois voir : par exemple 192.168.1.23:1880/ui : le même dashboard, qui bouge en même temps que celui du PC.

Si la page ne s'ouvre pas, le pare-feu de Windows bloque sans doute Node.js : autorise-le sur le réseau privé quand Windows le demande.
