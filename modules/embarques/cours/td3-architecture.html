RISC et CISC, Harvard, DMA

Trois comparaisons du chapitre 2 : comment le processeur est conçu (RISC ou CISC), comment il relie ses mémoires (Von Neumann, Harvard, Super Harvard), et comment les données des périphériques arrivent en mémoire (le processeur lui-même, ou le DMA).

Question 6 : RISC et CISC

On te demande. Donne trois caractéristiques des processeurs RISC et CISC.

Réponse. D'après le tableau du cours :

RISC (Reduced Instruction Set Computer)CISC (Complex Instruction Set Computer)
la complexité est dans le logiciel (le compilateur)la complexité est dans le matériel
instructions simples, réduites, d'un cycle d'horlogeinstructions complexes de plusieurs cycles
de registre à registre : LOAD et STORE sont des instructions à partde mémoire à mémoire : LOAD et STORE sont inclus dans les instructions
code plus long, peu de cycles par instructioncode court, beaucoup de cycles
les transistors servent surtout aux registresles transistors servent à stocker les instructions complexes

Exemples : AVR, ARM, PIC et les cœurs Xtensa de l'ESP32 sont RISC ; les processeurs x86 des PC sont CISC.

Question 7 : Von Neumann, Harvard, Super Harvard

On te demande. Compare les trois architectures.

Réponse.

Von NeumannHarvardSuper Harvard
Mémoiresune seule, pour les données et les instructionsdeux : Program Memory (instructions) et Data Memory (données)comme Harvard
Busun bus d'adresses et un bus de données, partagésdeux paires de bus : PM Address et PM Data, DM Address et DM Datacomme Harvard
En plusrienrienun cache d'instructions et un contrôleur d'entrées-sorties dédié (I/O Controller), relié à la Data Memory
Vitesseinstructions et données font la queue sur le même buslecture d'une instruction et accès à une donnée en même temps : rapideencore plus rapide : les données des entrées-sorties arrivent en mémoire sans passer par le CPU

Avec le modèle de comptage du cours (une instruction et une donnée, un cycle de bus chacune) : \(N\) instructions demandent \(2N\) cycles en Von Neumann, \(N + 1\) en Harvard.

Question 8 : scrutation, interruption ou DMA

On te demande. Compare deux façons de gérer les entrées-sorties : par scrutation ou interruption, et par DMA (Direct Memory Access).

Ce qu'il faut savoir.

  • Scrutation (polling) : le programme lit sans cesse le registre d'état du périphérique pour savoir si une donnée est prête.
  • Interruption : le périphérique prévient le CPU par un signal ; le CPU suspend le programme, exécute la routine d'interruption qui lit la donnée, puis reprend.
  • DMA : d'après le cours, transferts rapides entre périphériques et mémoire, ou de mémoire à mémoire, sans aucune intervention du CPU.

Réponse.

Scrutation ou interruptionDMA
chaque donnée passe par le CPU : il la lit dans le périphérique puis l'écrit en mémoirela donnée va directement du périphérique à la mémoire, le CPU n'y touche pas
simple à programmerconfiguration plus lourde (adresses, nombre d'octets, descripteurs)
scrutation : le CPU perd son temps à attendre ; interruption : il est dérangé à chaque donnée (sauvegarde et restauration du contexte)le CPU reste libre pour calculer ; il est prévenu une fois, quand tout le bloc est arrivé
adapté aux événements rares ou lents : un bouton, une commande sérieadapté aux gros flux : ADC rapide, ECG à haute cadence, son, image, Wi-Fi

Exemple du cours : un holter à 500 échantillons de 2 octets par seconde ; le DMA copie 1 000 octets par seconde de l'ADC vers la SRAM interne, sans un cycle de CPU, pendant que le programme calcule le rythme cardiaque.

À retenir

  • RISC : simple, un cycle, registre à registre, complexité dans le logiciel ; CISC : l'inverse.
  • Von Neumann : une mémoire, un bus ; Harvard : deux mémoires, deux bus ; Super Harvard : plus un cache d'instructions et un contrôleur d'entrées-sorties.
  • Scrutation et interruption : le CPU transporte chaque donnée ; DMA : la donnée va seule en mémoire.
