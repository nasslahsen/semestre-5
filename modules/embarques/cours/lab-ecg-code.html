Lab 2 : Bluetooth Biomedical Data Communication

Objectif du lab : acquérir des données ECG sur l'ESP32 et les envoyer à un autre appareil par une liaison Bluetooth. Pas besoin d'électrodes : le programme rejoue un battement cardiaque enregistré dans un tableau de 350 échantillons.

Étape 1 : coller le programme du cours

Rien à installer : BluetoothSerial.h vient avec les cartes ESP32. Le tableau EcgWaveForm est recopié en entier : ne le raccourcis pas.

void callback(esp_spp_cb_event_t event, esp_spp_cb_param_t *param) {
  if (event == ESP_SPP_SRV_OPEN_EVT) {
    Serial.println("Client Connected");
    digitalWrite(LED_BUILTIN, HIGH);
    BT_cnx = true;
  }
  if (event == ESP_SPP_CLOSE_EVT) {
    Serial.println("Client disconnected");
    digitalWrite(LED_BUILTIN, LOW);
    BT_cnx = false;
    ESP.restart();
  }
}

void setup() {
  // initialize digital pin 2 as an output.
  pinMode(LED_BUILTIN, OUTPUT);
  // initialize the serial communication:
  Serial.begin(115200);
  Serial.println(); // blank line in serial ...
  // initialize the serial BT communication:
  ESP_BT.register_callback(callback);
  if (!ESP_BT.begin("ESP32_ECG")) {
    Serial.println("An error occurred initializing Bluetooth");
  } else {
    Serial.println("Bluetooth initialized... Bluetooth Device is Ready to Pair...");
  }
}

void loop() {
  ecgSample = ecgSample + 1;
  if (ecgSample >= NECGSamples) ecgSample = 0;
  // send the value of analog input 0 to serial:
  Serial.println(EcgWaveForm[ecgSample]);
  // Do the same for bluetooth
  if (BT_cnx) {
    ESP_BT.print('E');
    // ESP_BT.println(analogRead(A0));
    ESP_BT.print(EcgWaveForm[ecgSample] / 2);
    ESP_BT.print(',');
    ESP_BT.println(EcgWaveForm[ecgSample] / 2 + 200); // send an other signal
  }
  // Wait a little to keep serial data from saturating
  delay(10);
}

Étape 2 : comprendre le programme

  • EcgWaveForm : un battement, 350 valeurs entre 2 et 255 (onde P, complexe QRS au pic de 255, onde T). loop() les lit l'une après l'autre et recommence au début.
  • delay(10) : environ 10 ms par échantillon, donc un battement d'environ 3,5 s (un peu plus avec le temps d'envoi).
  • ESP_BT.begin("ESP32_ECG") : la carte apparaît sous ce nom en Bluetooth.
  • callback : à la connexion d'un appareil, la LED de la broche 2 s'allume et l'envoi Bluetooth commence ; à la déconnexion, la LED s'éteint et la carte redémarre (ESP.restart()).
  • Chaque ligne Bluetooth a la forme E, valeur / 2, virgule, valeur / 2 + 200 : deux courbes décalées, pour l'application de tracé.

Étape 3 : téléverser et voir l'ECG sur le PC

Upload, puis Tools, Serial Plotter (et non Serial Monitor), à 115200 bauds.

Tu dois voir : la courbe d'un ECG qui défile, un battement après l'autre, avec un pic net (le QRS) à chaque battement. Dans le Serial Monitor, la phrase Bluetooth initialized... Bluetooth Device is Ready to Pair... au démarrage.

Ce programme utilise le Bluetooth classique : il marche sur l'ESP32 de la DEV KIT V1. Les puces ESP32-S3 et ESP32-C3 n'ont que le Bluetooth Low Energy, et BluetoothSerial n'y compile pas.
