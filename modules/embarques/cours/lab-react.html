Lab 3 : React App

Lancer l'analyse à la main ne sert à rien en vrai : React la déclenche toute seule quand une donnée arrive. React marche avec ThingHTTP, ThingTweet et MATLAB Analysis, pour agir quand les données d'un channel remplissent une condition.

Étape 1 : créer la réaction

Apps, React, New React. Les réglages de la capture du cours :

  • React Name : ReactStateCounter ;
  • Condition Type : String ; Test Frequency : On Data Insertion ;
  • Condition : If channel counterAcquisition, field 5 (EPF), is not equal to 0 ;
  • Action : MATLAB Analysis ; Code to execute : stateCounterMatlab ;
  • Options : Run action each time condition is met.

Save React.

Tu dois voir : ReactStateCounter dans la liste, cochée.

Étape 2 : comprendre les réglages

  • Condition Type : String, Status, Numeric, Geo Location ou No Data Check (vérifie que le channel reçoit bien des données à l'intervalle prévu).
  • Test Frequency : On Data Insertion (à chaque nouvelle donnée), ou toutes les 10, 30 ou 60 minutes, à l'heure pile.
  • Options : « only the first time » agit seulement quand la condition passe de fausse à vraie ; « each time » agit à chaque fois qu'elle est vraie.
  • Si l'analyse MATLAB plante plusieurs fois de suite, React s'arrête : coche « Notify me via email » dans l'analyse pour être prévenue.

Étape 4 : régler l'affichage d'un graphique

Un graphique de channel s'ouvre aussi par une requête HTTP GET, avec ses réglages dans l'adresse : title (titre), color (couleur de la ligne), width (largeur en pixels), xaxis (nom de l'axe).

https://api.thingspeak.com/channels/0000000/charts/1?title=Voltage&color=FF69B4&width=850&xaxis=Time

Tu dois voir : le graphique du champ 1, titré Voltage, avec une ligne rose et l'axe horizontal nommé Time. Si le channel est privé, ajoute &api_key=TA_CLE_READ à la fin.
