Préparer l'Arduino IDE pour l'ESP32

Les labs suivants se programment dans l'Arduino IDE, sur la carte ESP32 DEV KIT V1. Cette partie installe la carte et les trois bibliothèques des labs, une fois pour toutes.

Étape 1 : installer l'Arduino IDE

Télécharge l'Arduino IDE (version 2) : arduino.cc/en/software, et installe-le.

Étape 2 : ajouter les cartes ESP32

File, Preferences. Dans « Additional boards manager URLs », colle l'adresse des cartes d'Espressif :

https://espressif.github.io/arduino-esp32/package_esp32_index.json

OK, puis Tools, Board, Boards Manager. Cherche esp32 et installe « esp32 by Espressif Systems ».

Tu dois voir : « INSTALLED » sous esp32 by Espressif Systems.

Étape 3 : choisir la carte et le port

Branche l'ESP32 en USB. Tools, Board, esp32, DOIT ESP32 DEVKIT V1. Puis Tools, Port : le port de la carte (COM3, COM4… sous Windows).

Si aucun port n'apparaît : essaie un autre câble (certains ne font que charger), puis installe le pilote USB de la puce de ta carte, en général CP210x (Silicon Labs) ou CH340.

Étape 4 : installer les bibliothèques des labs

Sketch, Include Library, Manage Libraries. Cherche et installe :

  • ArduinoJson de Benoit Blanchon (lab 2) ;
  • ThingSpeak de MathWorks (lab 3) ;
  • PubSubClient de Nick O'Leary (labs 4 et 6).

Les bibliothèques WiFi.h et BluetoothSerial.h viennent avec les cartes ESP32 : rien à installer.

Le code du cours est écrit pour ArduinoJson 6 (StaticJsonDocument, createNestedArray). Pour suivre sans surprise, choisis une version 6.x dans la liste des versions. La version 7 compile aussi, avec des avertissements « deprecated ».

Étape 5 : téléverser et ouvrir le moniteur série

Pour chaque programme : bouton Upload (flèche vers la droite), puis Tools, Serial Monitor, et règle la vitesse (en bas à droite) sur celle de Serial.begin : 9600 pour ce lab, 115200 pour les suivants.

Si le téléversement s'arrête sur Connecting.... puis Failed to connect, maintiens le bouton BOOT de la carte pendant que les points s'affichent, puis relâche.
