MQTT Implementation on ESP32 board : le programme

Le modèle du cours : l'ESP32 lit une mesure sur A0 et la publie toutes les 2 s sur ensam/gbm/temperature ; il s'abonne à ensam/gbm/light pour allumer ou éteindre la LED de la broche 2. Le broker est public : test.mosquitto.org.

Étape 1 : les étapes d'un programme IoT

Le cours découpe le programme en sept étapes, que tu retrouves dans l'ordre dans le code :

  1. déclaration des bibliothèques ;
  2. déclaration des paramètres : réseau Wi-Fi, serveur MQTT ;
  3. création des objets : espClient, client ;
  4. fonction setup ;
  5. fonction callback : lecture du message et décision ;
  6. fonction reconnect ;
  7. loop : reconnexion, acquisition, publication des messages.

Étape 2 : coller le programme

Le programme des diapositives, en un seul bloc. Bibliothèque nécessaire : PubSubClient.

#include <WiFi.h>
#include <PubSubClient.h>

const char* ssid = "TON_WIFI";             // "REPLACE_WITH_YOUR_SSID"
const char* password = "TON_MOT_DE_PASSE"; // "REPLACE_WITH_YOUR_PASSWORD"
// Add your MQTT Broker IP address, example:
const char* mqtt_server = "test.mosquitto.org"; // "YOUR_MQTT_BROKER_IP_ADDRESS"

WiFiClient espClient;
PubSubClient client(espClient);
long lastMsg = 0;
char msg[50];
int value = 0;
float temp = 0;
// LED Pin
const int ledPin = 2;

void setup_wifi() {
  delay(10);
  // We start by connecting to a WiFi network
  Serial.println();
  Serial.print("Connecting to ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("");
  Serial.println("WiFi connected");
  Serial.println("IP address: ");
  Serial.println(WiFi.localIP());
}

void callback(char* topic, byte* message, unsigned int length) {
  Serial.print("Message arrived on topic: ");
  Serial.print(topic);
  Serial.print(". Message: ");
  String messageTemp;
  for (int i = 0; i < length; i++) {
    Serial.print((char)message[i]);
    messageTemp += (char)message[i];
  }
  Serial.println();

  // Changes the output state according to the message
  if (String(topic) == "ensam/gbm/light") {
    Serial.print("Light: Changing output to ");
    if (messageTemp == "on") {
      Serial.println("on");
      digitalWrite(ledPin, HIGH);
    }
    else if (messageTemp == "off") {
      Serial.println("off");
      digitalWrite(ledPin, LOW);
    }
  }
}

void reconnect() {
  // Loop until we're reconnected
  while (!client.connected()) {
    Serial.print("Attempting MQTT connection...");
    // Attempt to connect
    if (client.connect("ESP8266Client")) {
      Serial.println("connected");
      // Subscribe
      client.subscribe("ensam/gbm/light");
    } else {
      Serial.print("failed, rc=");
      Serial.print(client.state());
      Serial.println(" try again in 5 seconds");
      // Wait 5 seconds before retrying
      delay(5000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  // default settings
  setup_wifi();
  client.setServer(mqtt_server, 1883);
  client.setCallback(callback);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (!client.connected()) {
    reconnect();
  }
  client.loop();
  long now = millis();
  if (now - lastMsg > 2000) {
    lastMsg = now;
    // Temperature in degC
    temp = 1.5 * analogRead(A0) / 600;
    // Convert the value to a char array
    char tempString[8];
    dtostrf(temp, 1, 2, tempString);
    Serial.print(" Temperature : ");
    Serial.println(tempString);
    client.publish("ensam/gbm/temperature", tempString);
  }
}

Deux corrections par rapport aux diapositives, sinon le programme ne compile pas : la dernière ligne publie tempString (la diapositive écrit currentString, qui n'existe pas), et le test du topic utilise des guillemets droits (la diapositive a un guillemet typographique « “ » devant ensam).

Étape 3 : régler le Wi-Fi et brancher la mesure

  • ssid et password : ton Wi-Fi (2,4 GHz).
  • A0 correspond à la broche GPIO36 (VP) de l'ESP32 DEV KIT V1. Branches-y le capteur, ou un potentiomètre entre 3,3 V et GND pour faire varier la valeur. Sans rien de branché, la mesure flotte au hasard.
  • La LED de la broche 2 est la LED bleue de la carte : rien à câbler.

Étape 4 : éviter les collisions sur un broker public

test.mosquitto.org est partagé par tout le monde. Si deux cartes de la classe utilisent le même Client ID ESP8266Client, elles se déconnectent l'une l'autre ; et quiconque publie on sur ensam/gbm/light allume ta LED. Pour tester seule, change le Client ID et ajoute ton prénom aux deux topics :

if (client.connect("ESP32-ton-prenom")) {
  client.subscribe("ensam/gbm/ton-prenom/light");

et remplace aussi ensam/gbm/light dans le callback, et ensam/gbm/temperature dans loop(), par tes topics. Sinon, garde ceux du cours.

Tu dois voir : après le téléversement (Serial Monitor à 115200 bauds) : WiFi connected, l'adresse IP, Attempting MQTT connection...connected, puis une ligne Temperature : … toutes les 2 s.
