Power meter : MQTT et format JSON

Un compteur envoie sa tension et son courant dans un seul message JSON, {"V": 220, "I": 20}. Node-RED doit le découper et calculer la puissance (partie 3 du cours, Power meter).

Étape 1 : recevoir le message brut

Le format JSON : des paires clé-valeur entre accolades, {"key1": "value1", "key2": "value2"}. Exemple du cours : {"V": 220, "I": 20}.

  1. Glisse un nœud mqtt in : le broker 127.0.0.1:1883 de la partie précédente, Topic sensors, QoS 2, Output « auto-detect (string or buffer) ». Done.
  2. Relie-le à un nœud debug, puis Deploy.

Publie le message JSON depuis la ligne de commande. Sous Windows, les guillemets intérieurs s'échappent avec \ :

cd "C:\Program Files\mosquitto"
mosquitto_pub -h localhost -t sensors -m "{\"V\":\"220\",\"I\":\"20\"}"
mosquitto_pub -h localhost -t sensors -m '{"V":"220","I":"20"}'

Tu dois voir : dans debug, sensors : msg.payload : string[20] et le texte "{"V":"220","I":"20"}" : pour l'instant, Node-RED ne voit qu'une chaîne de caractères.

Étape 2 : le nœud json

Ajoute un nœud json (catégorie parser) après mqtt in, et un deuxième debug à sa sortie. Deploy, puis renvoie la même commande.

Tu dois voir : dans le deuxième debug, msg.payload : Object avec V: "220" et I: "20". Le nœud json a transformé le texte en objet : on peut maintenant lire chaque champ.

Étape 3 : extraire chaque champ

Ajoute trois nœuds function à la sortie du nœud json. Dans chacun, onglet On Message, colle le code :

msg.payload=msg.payload.I
return msg;
msg.payload=msg.payload.V
return msg;
msg.payload=msg.payload.V*msg.payload.I;
return msg;

Relie current et voltage à un debug, power à un autre. Deploy, puis renvoie la commande.

Tu dois voir : la fenêtre de résultat du cours : la chaîne, l'objet, puis "20" (current), "220" (voltage) et 4400 (power, un nombre). JavaScript a converti les deux chaînes en nombres pour la multiplication : 220 × 20 = 4400.

Le code de la fonction power n'est pas visible dans le cours, seulement son résultat (4400) : celui-ci donne bien ce résultat.
