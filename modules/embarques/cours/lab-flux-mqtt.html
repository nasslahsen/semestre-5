Un premier flux MQTT : sensors/voltage

Node-RED publie une tension sur le topic sensors/voltage et la reçoit aussitôt, en passant par le broker Mosquitto. C'est le premier aller-retour du lab (partie 2 du cours, MQTT communication on Node-RED and Mosquitto server).

Étape 1 : préparer

Vérifie que Mosquitto tourne (service ou mosquitto -v), lance node-red, puis ouvre http://127.0.0.1:1880.

Étape 2 : construire le flux

Le flux du cours a deux lignes. Les nœuds sont dans les catégories common et network de la palette.

  1. Glisse un nœud inject (common). Double-clique : msg.payload de type number, valeur 25. Done.
  2. Glisse un nœud mqtt out (network) et relie la sortie de inject à son entrée. Double-clique : Topic sensors/voltage ; laisse QoS et Retain vides.
  3. À côté de Server, clique sur le crayon pour créer le broker. Onglet Connection : Server 127.0.0.1, Port 1883, Protocol MQTT V3.1.1, Client ID vide, Keep Alive 60, Use clean session coché. Update, puis Done.
  4. Dessous, glisse un nœud mqtt in : Server le même broker, Topic sensors/voltage. Done.
  5. Glisse un nœud debug, nomme-le Circuit_V1, et relie mqtt in à debug.

Tu dois voir : deux lignes : inject → sensors/voltage, et sensors/voltage → Circuit_V1.

Étape 3 : déployer et tester avec le bouton

Clique sur Deploy (en haut à droite). Ouvre le panneau debug (icône d'insecte, à droite). Clique sur le petit carré à gauche du nœud inject.

Tu dois voir : sous les deux nœuds MQTT, un point vert « connected » ; dans le panneau debug : sensors/voltage : msg.payload : number puis 25.

Si les nœuds MQTT restent sur « connecting », le broker ne tourne pas : relance Mosquitto (étape 5 de l'installation).

Étape 4 : publier depuis la ligne de commande

Ouvre une deuxième invite de commandes, place-toi dans le dossier de Mosquitto, et publie une valeur sur le même topic :

cd "C:\Program Files\mosquitto"
mosquitto_pub -h localhost -t sensors/voltage -m 30

Tu dois voir : dans le panneau debug de Node-RED, "30" (une chaîne, puisqu'elle vient du texte de la commande).

Sans -t devant le topic, Mosquitto répond Error: Unknown option 'sensors/voltage', comme dans la capture du cours : -h donne le broker, -t le topic, -m le message.

Étape 5 : s'abonner depuis la ligne de commande

mosquitto_sub -h localhost -t sensors/voltage

Laisse cette fenêtre ouverte, puis clique à nouveau sur le bouton du nœud inject dans Node-RED.

Tu dois voir : 25 s'affiche dans la fenêtre de mosquitto_sub à chaque clic. Le broker distribue le message à tous les abonnés : Node-RED et la ligne de commande.
