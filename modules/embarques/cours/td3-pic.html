L'architecture d'un microcontrôleur PIC

La question 9 donne le schéma interne d'un microcontrôleur PIC de Microchip, de la famille PIC18 (instructions de 16 bits, jusqu'à 64 MHz). Il faut dire à quoi sert chaque bloc. On y retrouve tout le chapitre 2 : CPU, deux mémoires séparées, pile, horloge, périphériques.

Question 9 : le rôle de chaque bloc

On te demande. Précise le rôle de chaque bloc du schéma.

Ce qu'il faut savoir.

  • Un CPU lit une instruction à l'adresse donnée par le compteur de programme (Program Counter, PC), l'exécute, puis passe à la suivante.
  • Une mémoire non volatile (flash, EEPROM) garde son contenu sans alimentation ; une RAM le perd.
  • Program Memory et Data Memory séparées, chacune reliée au CPU : c'est l'architecture Harvard.

Lecture du schéma :

  • La flèche rouge va de la Program Memory au CPU seule : c'est le chemin des instructions, séparé de celui des données. Architecture Harvard.
  • 83 instructions seulement : un jeu d'instructions réduit, le PIC est un RISC.
  • EUSART est un UART amélioré (Enhanced Universal Synchronous Asynchronous Receiver Transmitter) : il sait aussi travailler en mode synchrone.

Complément : la famille PIC n'est pas décrite dans les diapositives ; le schéma se lit comme celui de l'AVR du chapitre 2, qui a les mêmes blocs (CPU, flash, SRAM, EEPROM, oscillateurs, ADC, USART, SPI, TWI, timers).

À retenir

  • Programme en flash (Program Memory), variables en RAM (Data Memory), réglages en EEPROM.
  • PC : prochaine instruction ; pile : adresses de retour (16 niveaux ici).
  • Deux mémoires, deux chemins : Harvard ; 83 instructions : RISC.
