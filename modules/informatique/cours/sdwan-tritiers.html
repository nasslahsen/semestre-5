Architectures SD-WAN et tri-tiers

Un CHU, trois centres de santé de quartier et un cabinet de radiologie doivent partager le DPI et le PACS. Deux questions se posent : comment relier les sites, et comment ranger les serveurs dans le datacenter.

SD-WAN : relier les sites

Le SD-WAN (Software Defined Wide Area Network) est l'architecture moderne par excellence pour connecter des sites distants : hôpitaux périphériques, cliniques, cabinets de radiologie.

Principe : le SD-WAN virtualise le contrôle du réseau. Il combine plusieurs liaisons physiques (par exemple une fibre et un secours en 4G/5G ou VSAT) et gère le trafic de manière intelligente, par logiciel.

Le schéma du cours :

  • un orchestrateur SD-WAN : politique centrale, supervision et journaux (SIEM) ;
  • un site principal (hub) avec un pare-feu SD-WAN en haute disponibilité et le datacenter (DPI, PACS, bases) ;
  • des centres de santé A et B, chacun avec son pare-feu SD-WAN (edge de site) et son LAN (postes, IoMT) ;
  • des tunnels IPsec chiffrés (l'overlay) au-dessus du réseau de transport (l'underlay : fibre ou MPLS, Internet haut débit, 4G/5G).

Tri-tiers : ranger les serveurs

L'architecture tri-tiers (multi-niveaux) est recommandée pour les applications critiques et les environnements de datacenters. Elle isole hermétiquement les composants d'une application en trois zones distinctes, séparées par des pare-feu.

NiveauContenuPare-feu devant (ce qu'il laisse passer)
1. Présentation (DMZ)reverse proxy, WAF, portail patientpare-feu 1, périmétrique : HTTPS 443 entrant uniquement
2. Applicationserveurs applicatifs : DPI, API, moteur d'interfacepare-feu 2, interne : port applicatif dédié, depuis la DMZ seule
3. Donnéesbases de données, stockage PACSpare-feu 3, données : requêtes SQL depuis l'application seule

En transversal : SIEM / IDS (journalisation), bastion (administration), sauvegarde isolée du réseau.

Le bénéfice : si un pirate compromet le serveur web exposé sur Internet, il ne peut pas accéder directement à la base de données qui contient les informations sensibles.

À retenir

  • SD-WAN : relier des sites ; plusieurs liaisons (fibre, 4G/5G, VSAT) pilotées par logiciel, tunnels IPsec, orchestrateur central.
  • Tri-tiers : présentation (DMZ), application, données, séparées par trois pare-feu.
  • Chaque niveau ne parle qu'au niveau voisin : le serveur web piraté n'atteint pas la base.
