TD 1 : les réponses dans le cours

Le TD 1 « Applications matériaux polymères / plastiques » tourne autour de trois nombres : la température de transition vitreuse \(T_g\), la température de fusion \(T_f\) et le taux de cristallinité \(X\). Avec eux, on sait dire si un polymère est rigide ou souple, transparent ou opaque, et combien il pèse. Cette page te dit où chercher chaque réponse.

Intuition

Pour un polymère semi-cristallin, place la température de la question sur l'axe, par rapport à \(T_g\) et \(T_f\). En dessous de \(T_g\), la phase amorphe est vitreuse : module élevé. Entre \(T_g\) et \(T_f\), elle est caoutchouteuse mais les cristaux tiennent encore : le module baisse un peu, le polymère reste translucide ou opaque. Au-dessus de \(T_f\), les cristaux ont fondu : \(X = 0\), le module chute vers 1 MPa et le polymère devient transparent.

Trois règles suffisent pour presque tout le TD :

  • un polymère possible a toujours \(T_f > T_g\), et au-dessus de \(T_f\) son taux de cristallinité est nul ;
  • cristaux présents : translucide ou opaque ; \(X = 0\) au-dessus de \(T_f\) : transparent ;
  • la vitesse de cristallisation est la plus élevée vers \((T_f + T_g)/2\).

Exemple

Exemple ajouté, sur un polymère qui n'est pas celui du TD : \(T_g = 0\) °C, \(T_f = 120\) °C, \(X = 0{,}6\) à 25 °C. À 25 °C, on est entre \(T_g\) et \(T_f\) : phase amorphe caoutchouteuse, cristaux présents, donc translucide ou opaque. À 130 °C, au-dessus de \(T_f\) : \(X = 0\), transparent, module de l'ordre du MPa. En le refroidissant depuis l'état fondu, il cristallise le plus vite vers \((120 + 0)/2 = 60\) °C.

Formules clés

\[\rho = \rho_c\,X + \rho_a\,(1 - X) \qquad X = \frac{\rho - \rho_a}{\rho_c - \rho_a} \qquad T_{cristallisation\ max} \approx \frac{T_f + T_g}{2}\]

\(T < T_g\) : vitreux ; \(T_g < T < T_f\) : amorphe caoutchouteux et cristaux ; \(T > T_f\) : fondu, \(X = 0\), transparent.
