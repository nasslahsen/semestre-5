Planification de biopsie : le MGI du robot 2R

Le robot 2R de biopsie doit placer son aiguille en \((50, 40)\) cm, coude vers le bas pour éloigner les moteurs de la zone stérile. On trouve \(\theta_1\) et \(\theta_2\) par la méthode analytique.

Intuition

La base O, le coude A et la cible P forment un triangle dont on connaît les trois côtés : \(OA = L_1\), \(AP = L_2\), \(OP = r\). Avec trois côtés connus, la loi des cosinus (théorème d'Al-Kashi) donne les angles. L'angle au coude donne \(\theta_2\) ; l'angle en O, ajouté à la direction de la cible, donne \(\theta_1\).

Formalisation

Données du cours : \(L_1 = 40\) cm, \(L_2 = 30\) cm ; MGD \(x = L_1\cos\theta_1 + L_2\cos(\theta_1 + \theta_2)\), \(y = L_1\sin\theta_1 + L_2\sin(\theta_1 + \theta_2)\) ; point cible \((x_c, y_c) = (50, 40)\) cm.

Étape 1 : vérification de l'accessibilité

Avant de calculer quoi que ce soit, l'algorithme vérifie que le point cible est physiquement atteignable :

\[ r = \sqrt{x_c^2 + y_c^2} = \sqrt{50^2 + 40^2} = \sqrt{4100} \approx 64{,}03 \text{ cm} \]

Le point est accessible si \(|L_1 - L_2| \leq r \leq L_1 + L_2\). Portée maximale (bras tendu) : 70 cm ; portée minimale (bras replié) : 10 cm. Puisque \(10 \leq 64{,}03 \leq 70\), le point est accessible. Sinon, il n'y a pas de solution.

Étape 2 : calcul de \(\theta_2\) (angle du coude)

Dans le triangle OAP, l'angle au sommet A est \(\beta = \pi - \theta_2\), et \(r\) est le côté opposé. Loi des cosinus :

\[ r^2 = L_1^2 + L_2^2 - 2L_1L_2\cos\beta \quad\Rightarrow\quad r^2 = L_1^2 + L_2^2 + 2L_1L_2\cos\theta_2 \] \[ \cos\theta_2 = \frac{x_c^2 + y_c^2 - L_1^2 - L_2^2}{2L_1L_2} \qquad \theta_2 = \pm\arccos\left(\frac{x_c^2 + y_c^2 - L_1^2 - L_2^2}{2L_1L_2}\right) \] \[ \cos\theta_2 = \frac{4100 - 1600 - 900}{2 \times 40 \times 30} = \frac{1600}{2400} = \frac{2}{3} \qquad \theta_2 = \pm\arccos\frac{2}{3} \approx \pm 48{,}19° \]

Le \(\pm\) montre qu'il y a deux solutions. Selon la contrainte médicale, le cours retient \(\theta_2 = 48{,}19°\).

Étape 3 : calcul de \(\theta_1\) (angle de l'épaule)

On trace la droite OP. \(\alpha\) est l'angle entre l'axe horizontal et OP ; \(\beta\) est l'angle entre le premier bras OA et OP (ici, dans le triangle, au sommet O). Dans la configuration retenue, \(\alpha = \theta_1 + \beta\), donc \(\theta_1 = \alpha - \beta\).

\[ \tan\alpha = \frac{40}{50} \;\Rightarrow\; \alpha = \arctan\left(\frac{40}{50}\right) = 38{,}66° \] \[ L_2^2 = L_1^2 + r^2 - 2L_1r\cos\beta \;\Rightarrow\; \beta = \arccos\left(\frac{L_1^2 + r^2 - L_2^2}{2L_1r}\right) = 20{,}44° \] \[ \theta_1 = \alpha - \beta = 38{,}66° - 20{,}44° = 18{,}22° \]

Interprétation : le premier bras s'élève à 18,2° par rapport à l'horizontale, le second redescend de 48° par rapport au prolongement du premier, l'aiguille atteint \((50, 40)\) cm et les moteurs restent éloignés du champ opératoire stérile.

Étape 4 : choisir la configuration adaptée à l'environnement

Configuration\(\theta_1\)\(\theta_2\)Contrainte
Coude bas18,22°+48,19°dégage l'équipement
Coude haut59,10°−48,19°rencontre l'équipement fixe représenté

On retient \(\theta_1 = 18{,}22°\) et \(\theta_2 = 48{,}19°\). Pour la configuration coude haut, \(\theta_1 = \alpha + \beta = 59{,}10°\).

Le cours appelle « coude bas » la solution \(\theta_2 = +48{,}19°\) (tableau de l'étape 4), alors qu'une ligne de l'étape 2 associe le coude bas à \(\theta_2 < 0\). Les exercices suivent le tableau.

Étape 5 : vérifier le résultat avec la MGD

\[ x = 40\cos(18{,}22°) + 30\cos(18{,}22° + 48{,}19°) \approx 50 \text{ cm} \qquad y = 40\sin(18{,}22°) + 30\sin(18{,}22° + 48{,}19°) \approx 40 \text{ cm} \]

La configuration retenue atteint bien la cible \(P_c = (50, 40)\) cm.

Exemple

Exemple ajouté.

Même robot, cible \((40, 30)\) cm. \(r = 50\) cm, accessible. \(\cos\theta_2 = (2500 - 1600 - 900)/2400 = 0\), donc \(\theta_2 = \pm 90°\). \(\alpha = \arctan(30/40) = 36{,}87°\) ; \(\cos\beta = (1600 + 2500 - 900)/(2 \times 40 \times 50) = 0{,}8\), donc \(\beta = 36{,}87°\). Coude bas : \(\theta_1 = \alpha - \beta = 0°\), \(\theta_2 = 90°\) : bras 1 à l'horizontale, bras 2 vertical. Vérification : \(x = 40 + 0 = 40\), \(y = 0 + 30 = 30\).

Formules clés

\[ r = \sqrt{x_c^2 + y_c^2} \qquad \cos\theta_2 = \frac{x_c^2 + y_c^2 - L_1^2 - L_2^2}{2L_1L_2} \] \[ \alpha = \arctan\frac{y_c}{x_c} \qquad \beta = \arccos\frac{L_1^2 + r^2 - L_2^2}{2L_1r} \qquad \theta_1 = \alpha - \beta \]
