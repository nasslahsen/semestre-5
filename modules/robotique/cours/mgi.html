Modélisation géométrique inverse (MGI)

Le chirurgien choisit une cible sur l'imagerie. Le robot, lui, ne sait régler que les angles de ses moteurs. Il faut donc trouver les angles qui amènent l'outil sur la cible.

Intuition

La MGD va des angles vers la position. Le modèle inverse fait le chemin dans l'autre sens : on connaît le point visé, on cherche les angles. Ce chemin est plus difficile. Une cible trop loin n'a aucune solution ; une cible accessible en a souvent plusieurs, comme un bras qui peut atteindre le même point coude en haut ou coude en bas.

Formalisation

Définition et objectif

La modélisation géométrique inverse (MGI) a pour but de déterminer les valeurs des variables articulaires \(q\) nécessaires pour placer l'organe terminal (OT) à une position et une orientation désirées dans l'espace de travail. Mathématiquement, on cherche à inverser la fonction de la MGD :

\[ q = f^{-1}(X) \]

où \(X = [x, y, z, \phi, \theta, \psi]^T\) est le vecteur de posture désirée de l'outil (espace cartésien) et \(q = [q_1, q_2, \dots, q_n]^T\) le vecteur des variables articulaires à trouver (espace articulaire).

Les défis de la MGI

  1. La non-linéarité : inverser \(x = L_1\cos\theta_1 + L_2\cos(\theta_1 + \theta_2)\) et \(y = L_1\sin\theta_1 + L_2\sin(\theta_1 + \theta_2)\) n'est pas trivial ; une forme fermée n'est pas toujours disponible.
  2. L'existence des solutions : une cible hors de portée n'a aucune solution ; l'orientation souhaitée doit aussi être réalisable.
  3. La multiplicité des solutions : même position, plusieurs configurations (coude haut, coude bas) ; il faut choisir un jeu d'angles adapté.
  4. Les singularités : par exemple bras tendu, \(\theta_2 = 0\) ; la mobilité instantanée de l'outil est réduite (perte de rang de la jacobienne de position).

Les méthodes de résolution

Méthodes analytiques (ou géométriques) : elles utilisent la géométrie et la trigonométrie du robot pour résoudre les équations de manière exacte. Avantages : solution exacte, rapide (temps réel), toutes les solutions. Inconvénients : pas de méthode générale, difficile pour les robots complexes.

Méthodes numériques : elles partent d'une estimation initiale des angles et itèrent pour se rapprocher de la solution. La plus connue est la méthode de Newton-Raphson, qui utilise la matrice jacobienne \(J(q)\) pour linéariser la MGD autour d'une solution courante \(q_k\) :

\[ q_{k+1} = q_k + J^{-1}(q_k)\,\big(X_{cible} - f(q_k)\big) \]

Avantages : méthode générale (elle fonctionne pour n'importe quel robot), facile à implémenter. Inconvénients : convergence non garantie, lente, une seule solution.

Applications et importance

  • Planification chirurgicale pré-opératoire (chirurgie assistée par ordinateur) : le chirurgien choisit les points cibles, le logiciel calcule les trajectoires, le chirurgien vérifie et valide le plan.
  • Radiothérapie adaptative : suivi respiratoire d'une tumeur mobile du poumon ou du foie ; les angles du robot sont recalculés pour ajuster le faisceau.

Le MGI traduit la cible en configurations (la cible issue de l'imagerie est exprimée dans le repère du robot), permet de choisir une configuration compatible avec les limites et les obstacles, et, avec des solutions successives cohérentes, des gestes continus sans changement brusque de configuration.

Exemple

Exemple ajouté.

Le robot de biopsie du cours a \(L_1 = 40\) cm et \(L_2 = 30\) cm. Une cible à 75 cm de la base : 75 > 70 = \(L_1 + L_2\), aucune solution, quels que soient les angles. Une cible à 5 cm : 5 < 10 = \(|L_1 - L_2|\), aucune solution non plus. Une cible à 40 cm : deux solutions, coude haut et coude bas.

Formules clés

\[ q = f^{-1}(X) \qquad |L_1 - L_2| \leq r \leq L_1 + L_2 \qquad q_{k+1} = q_k + J^{-1}(q_k)\,\big(X_{cible} - f(q_k)\big) \]

Analytique : exacte, rapide, toutes les solutions. Numérique : générale, une seule solution, convergence non garantie.
